# Morphing rounded polygons in rust
This is a custom shape library targetted specifically towards [amane-shell](https://github.com/MystiaFin/amane)

# Intro
This is a Amane shell's port of [Knugel's Typescript port](https://github.com/Knugel/rounded-polygon-ts) with inspiration of [End4's rounded-polygon-qmljs](https://github.com/end4/rounded-polygon-qmljs). This includes the 35 [Material Design shapes](https://m3.material.io/styles/shape/overview-principles#579dd4ba-39f3-4e60-bd9b-1d97ed6ef1bf)

# Usage
You can use it as a submodule in your Amane shell based dotfiles
